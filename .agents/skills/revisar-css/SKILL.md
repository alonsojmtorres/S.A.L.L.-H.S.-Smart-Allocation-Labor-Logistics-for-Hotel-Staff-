name: revisar-css
description: Revisa una hoja de CSS y lista sus problemas. Úsala cuando te pida revisar, validar o mejorar mi CSS.
---

Cuando te pida revisar mi CSS:
1. Lee la hoja completa.
2. Busca erratas, valores que no existen y reglas que no se aplican a nada.
3. Comprueba que el texto se lee bien (contraste) y que el foco con teclado se ve.
4. Devuélveme una tabla línea, problema y corrección.
5. No cambies el fichero: propón las correcciones y espera a que te diga.
